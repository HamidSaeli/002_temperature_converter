# Project 002: Temperature Converter (Celsius to Fahrenheit)

**Short Description:**  
This project converts a temperature from Celsius to Fahrenheit using a simple formula.

**Skills Learned:**  
- Working with user input  
- Data type conversion  
- Applying formulas  
- Displaying output

**How to Run:**  
1. Open the `temperature_converter.ipynb` file in Jupyter Notebook.  
2. Execute the cells in order.  
3. Enter the temperature in Celsius to see the result in Fahrenheit.
